Install the QMOD
Import the QMOD with your mod manager, such as ModsBeforeFriday. Let it install CrashReporter if needed, launch Beat Saber, then reproduce the crash.
Open your crash reports 
Share the reports link with the person helping you. Reports appear after an upload; this page doesn’t check the analyzer.

    
Don’t see your game version?
Only versions with a CrashReporter release in the BSQuest catalog are listed. Reload the page to check for updates. Don’t install a package for a different game version.
What does this QMOD change?
It writes CrashReporter.json to your game’s Configs folder and declares CrashReporter as a required dependency. Installing it replaces your existing CrashReporter configuration with the settings you choose here.
